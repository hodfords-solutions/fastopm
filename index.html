fastopm Helm charts

Helm chart repository for fastopm, a read-only npm proxy cache written in Rust that reads Verdaccio's config.yaml and storage layout.

Add the repository

helm repo add fastopm https://hodfords-solutions.github.io/fastopm
helm repo update
helm search repo fastopm

Install the chart

helm install npm fastopm/fastopm --namespace npm --create-namespace
helm test npm --namespace npm

No fastopm image is published on Docker Hub yet. Build it from the repository's Dockerfile, push it to your registry and install with --set image.repository=<registry>/fastopm --set image.tag=<tag>.
